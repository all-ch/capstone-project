# Justifying the Family: A Semantic Analysis of Rhetorical Trends

## Allinn Chen, Rean Du, Tyler Tran, and David Wang

### How to Get Started

#### 1. Clone the Repository

```bash
git clone https://github.com/all-ch/capstone-project/tree/main
cd ./capstone-project
```

#### 2. Install `uv`

**macOS/Linux**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

#### 3. Installing Dependencies

```bash
uv sync
```

### How to Run

#### 1. Load Virtual Environment

```bash
source .venv/bin/activate
```

#### 2. Open JupyterLab

```bash
uv run jupyter lab
```

#### 3. Run the Script

Go to top menu and select **Run > Run All Cells**
